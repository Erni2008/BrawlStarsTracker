# Brawl Trophy Tracker

Локальный дашборд для Brawl Stars без Supercell API token: показывает дневной прирост кубков, историю по дням, текущих бравлеров и изменения кубков по бравлерам между снимками профиля.

## Бесплатная iPhone-версия как PWA

В папке `pwa/` лежит отдельная версия, которую можно бесплатно выложить как сайт и добавить на экран iPhone.

```bash
cd /Users/erni/Desktop/kahoot_clone/brawl_trophy_tracker/pwa
python3 -m http.server 8780
```

Открой локально:

```text
http://127.0.0.1:8780
```

Как поставить на iPhone после публикации:

1. Открыть ссылку в Safari.
2. Нажать `Поделиться`.
3. Выбрать `На экран «Домой»`.
4. Запустить как обычное приложение с иконки.

Что умеет PWA:

- работает без Apple Developer Program и без App Store;
- не требует Supercell token;
- хранит снимки профиля в браузере через `localStorage`;
- показывает дневную дельту кубков, бравлеров, историю, примерную оценку поражений;
- показывает активные и следующие карты отдельными блоками;
- открывает превью карты по нажатию;
- переключает интерфейс RU/EN.

Для бесплатной публикации подойдут GitHub Pages, Netlify или Vercel. Самый простой вариант: залить содержимое папки `pwa/` на GitHub Pages.

## Как запустить

```bash
cd /Users/erni/Desktop/kahoot_clone/brawl_trophy_tracker
python3 -m uvicorn app:app --reload --host 127.0.0.1 --port 8765
```

Открой:

```text
http://127.0.0.1:8765
```

## Настройка

1. Запусти приложение.
2. Введи `player tag`, например `#ABC123`.
3. Нажми `Сохранить`.
4. Нажми `Обновить`, чтобы сделать первый снимок.

Статистика хранится локально в:

```text
brawl_trophy_tracker/data/tracker.sqlite3
```

## Как работает статистика

- `Сегодня по снапшотам` считает разницу между первым и последним сохранённым замером профиля за день.
- `Бравлеры сегодня` сравнивает кубки каждого бравлера между первым и последним снимком дня.
- `Последние изменения` сравнивает два последних снимка профиля.
- Данные берутся из неофициального BSInfo API: https://api.bsinfox.com/
- Battle log в стабильном режиме без токена недоступен, поэтому трекер не показывает конкретные матчи.
- Чем чаще работает синхронизация, тем точнее дневная история. Хороший интервал: 5-15 минут.
