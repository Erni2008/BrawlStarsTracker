# Brawl Trophy Tracker iOS

SwiftUI-приложение для iPhone без Supercell API token.

## Что умеет

- Запрашивает публичный профиль через BSInfo API: `https://api.bsinfox.com/players/{tag}`.
- Сохраняет снимки профиля локально на телефоне.
- Показывает дневной прирост кубков по снимкам.
- Показывает журнал интервалов между снимками: прирост кубков, победы и оценочные поражения.
- Показывает изменения кубков по бравлерам между снимками.
- Показывает расширенные карточки бравлеров: портрет, кубки, сила, ранг, win streak, skin, пассивки, гаджеты, gears и hypercharge.
- Даёт поиск, фильтры и сортировку бравлеров: all, hyper, missing gears, Power 11, near milestone, dropped.
- Открывает детальный экран бравлера с графиком кубков, loadout-списками и активными усилениями.
- Smart Map Advisor подбирает бравлеров под текущие и следующие карты с учётом силы аккаунта, избранного, рубежей и антислива.
- Антислив-подсказки помечают бравлеров с просадкой и советуют паузу до следующего sync.
- Можно закреплять избранных бравлеров и вести цели по конкретным бравлерам.
- Позволяет поставить личную цель по кубкам и отслеживать прогресс до неё.
- Подсказывает, каких бравлеров выгоднее пушить до ближайшего рубежа.
- Есть блок "Что докачать" для power, gears, пассивок, гаджетов и hypercharge.
- Quality Score оценивает готовность аккаунта к пушу.
- Показывает календарь прогресса и недельную/месячную дельту.
- Строит личный tier-list по данным аккаунта: кубки, power, rank, streak и заполненность loadout.
- Есть Coach Feed с короткими уведомлениями внутри приложения.
- Можно поделиться текстовым дневным отчётом через системное Share Sheet.
- Есть настройки отображения сложных блоков и количества дней в календаре.
- Интерфейс разбит на нижние вкладки: Главная, Coach, Карты, Бравлеры, История, Настройки.
- Тяжёлые блоки можно сворачивать, чтобы не листать длинную страницу.
- Compact UI включён по умолчанию: меньше отступов, скрыты длинные пояснения, карты и бравлеры отображаются плотнее.
- Показывает текущую и следующую ротацию карт отдельными секциями через tokenless BrawlAPI: `https://api.brawlapi.com/v1/events`.
- Есть переключатель языка RU/EN: интерфейс, статусы, подсказки и блок карт переключаются без перезапуска.
- Названия карт показываются в двух языках: основной язык крупно, второй язык дополнительной строкой.
- Кэширует карты и throttles refresh, чтобы не дёргать API при каждом открытии приложения.
- Автоматически пробивает кэш карт, если сохранённый слот уже закончился.
- Позволяет открыть карту и посмотреть большое превью, режим, слот, старт, конец и время до смены или старта.
- Использует lazy-отрисовку и кэширует расчёты статистики, чтобы скролл держался плавнее.
- Работает только по `player tag`, без API key.

## Следующие native-модули

- watchOS target: компактная версия для Apple Watch.

## Как открыть

1. Открой `BrawlTrophyTrackerIOS.xcodeproj` в Xcode.
2. Выбери iPhone Simulator или подключённый iPhone.
3. Нажми Run.
4. Введи player tag и нажми кнопку обновления.

## Ограничение

В стабильном режиме без токена нет battle log endpoint, поэтому приложение не видит конкретные матчи с картой, режимом и составами. Раздел "Батл лог" строится по снимкам профиля: победы считаются по росту счётчиков `3v3/Solo/Duo wins`, а поражения оцениваются по видимому минусу кубков и по скрытому минусу, когда победы есть, но общий прирост кубков ниже ожидаемого. Точность дневной статистики зависит от того, как часто ты делаешь снимки профиля.
